Cost Optimization Strategies

How to reduce costs for different environments

Savings Plan / Reserved

1-year Compute Savings Plan for t3.large: ~40% discount. Reduces EC2 from $154 to ~$92/mo.

Savings: ~$62/mo ($744/yr)

Spot Instances

Use Spot for worker nodes (up to 70% savings). With 2 node groups (1 on-demand + 1 spot), maintain availability while cutting costs.

Savings: ~$54/mo on 1 spot node

Remove NAT Gateway

For demo/portfolio use, public subnets are acceptable. Eliminates $43.50/mo NAT Gateway cost entirely.

Savings: $43.50/mo

Fargate Profile

Replace EC2 nodes with EKS Fargate for workloads with variable demand. Pay only for pod-level vCPU/memory instead of full node allocation.

Trade-off: Higher per-pod cost but no idle capacity waste

Schedule-Based Scaling

Scale down to 0 nodes during off-hours (nights/weekends). For a demo cluster, this alone saves 65%+ on EC2.

Savings: ~$100/mo (assuming 8hr/day usage)

EKS on EC2 Alternative

Self-managed K8s (k3s) on EC2 eliminates the $73/mo EKS control plane fee. Trade-off: more operational overhead.

Savings: $73/mo (but adds ops burden)
