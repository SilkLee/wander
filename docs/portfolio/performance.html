Week 10 Optimizations

Systematic performance improvements across every layer

Optimization Layer Before After Improvement
Connection Pooling Go New conn per request Pooled (max 100) 3× throughput
HTTP Client Reuse Go New client per request Shared client + keep-alive 2× latency reduction
Redis Response Caching Go No caching TTL-based cache middleware 90% cache hit for reads
Gunicorn Multi-Worker Python 1 Uvicorn worker 4 Gunicorn workers 4× concurrent capacity
In-Memory TTL Cache Python DB query per request Cached with 60s TTL 10× faster reads
React.lazy Code Splitting React Single 450KB bundle Route-based lazy loading 60% smaller initial load
Vite Manual Chunks React Auto-chunked Vendor/UI/Chart splits Better cache hit ratio
